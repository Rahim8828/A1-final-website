# Banner Images

## Required Images

Place your banner images in this folder with the following names:

### Desktop Banners (1920×800px recommended)
- `banner_2_desktop.webp`
- `banner_3_desktop.webp`

### Mobile Banners (800×600px recommended)
- `banner_2_mobile.webp`
- `banner_3_mobile.webp`

## Image Specifications

### Desktop
- **Dimensions:** 1920×800px (or 16:9 aspect ratio)
- **Format:** WebP (for best performance)
- **File Size:** < 200KB (optimized)

### Mobile
- **Dimensions:** 800×600px (or 4:3 aspect ratio)
- **Format:** WebP (for best performance)
- **File Size:** < 150KB (optimized)

## Design Guidelines

1. **Text Placement:** Keep important text and CTAs in the bottom-left area
2. **Contrast:** Ensure good contrast for the price badge and CTA button
3. **Safe Area:** Keep critical content away from edges (50px margin)
4. **Mobile:** Ensure text is readable on smaller screens
